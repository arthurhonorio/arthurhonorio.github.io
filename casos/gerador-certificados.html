Geração em lote de certificados com sanitização de planilhas

Pipeline automatizado em Python para transformar registros de participantes em arquivos .docx personalizados, eliminando preenchimento manual e erros de tipagem de dados.

Código-fonte no GitHub ↗
Python 3 Pandas OpenPyXL docxtpl

1. O Problema

Emitir certificados individuais para eventos e ações comunitárias exigia copiar manualmente nomes e CPFs de uma planilha Excel para um documento Word, atualizar datas e salvar cada arquivo separadamente. Além de consumir horas de trabalho repetitivo, o processo manual estava sujeito a erros de digitação, inconsistência na data de emissão e emissão de documentos para cadastros incompletos.

2. Arquitetura e Fluxo de Execução

A solução foi desenhada como um script CLI enxuto e determinístico, separando completamente os dados de entrada (.xlsx), o layout visual (.docx) e a lógica de processamento: 

Planilha (.xlsx) ──▶ Pandas (dtype=str + limpeza) ──▶ Validação (Nome/CPF)
                                                               │
Certificados (.docx) ◀── Renderização Jinja2 (docxtpl) ◀───────┘

3. Decisões Técnicas e Casos de Borda

  • Preservação de zeros à esquerda no CPF (dtype=str) Por padrão, leitores de Excel inferem colunas numéricas como inteiros ou floats, amputando zeros iniciais de CPFs (ex.: 012... vira 12...). Forçar dtype=str na leitura com Pandas garante integridade documental sem precisar reconstruir máscaras.
  • Template engine com docxtpl em vez de edição crua de XML Alterar textos diretamente via python-docx costuma quebrar estilos quando o Word divide uma palavra em múltiplos runs XML. O docxtpl aplica sintaxe Jinja2 ({{ nome }}, {{ cpf }}, {{ data_emissao }}) mantendo 100% da tipografia, margens e identidade visual do modelo original.
  • Sanitização defensiva de linhas e sistema de arquivos O pipeline normaliza cabeçalhos (str.strip()), descarta automaticamente linhas vazias ou sem CPF válido (evitando gerar certificados corrompidos com "nan") e remove caracteres proibidos (/) antes de gravar o arquivo final no disco com pathlib.

4. Implementação Principal

df = pd.read_excel(caminho_excel, dtype=str)
df.columns = df.columns.str.strip()
data_atual = datetime.now().strftime("%d/%m/%Y")

for _, linha in df.iterrows():
    nome = str(linha["Nome"]).strip()
    cpf = str(linha["CPF"]).strip()

    if nome == "nan" or not nome or cpf in ("nan", "", "None", "none"):
        continue

    doc = DocxTemplate(caminho_modelo)
    doc.render({"nome": nome, "cpf": cpf, "data_emissao": data_atual})

    nome_arquivo = f"Certificado - {nome}.docx".replace("/", "-")
    doc.save(pasta_saida / nome_arquivo)

5. Resultado e Próximos Passos

O processo de emissão em lote caiu de horas de edição manual para poucos segundos de execução, com rastreabilidade no terminal sobre registros ignorados e saída padronizada em pasta dedicada.

Evoluções planejadas: conversão automática para PDF em lote (via LibreOffice headless) e passagem de caminhos via argumentos CLI (argparse) para reutilizar o script em diferentes eventos sem alterar o código.
